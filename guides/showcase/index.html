    The Event Showcase¶

    Want to see what all of this looks like in one go? The Event Showcase is a complete song - two minutes, 140 BPM, intro to outro - where every single effect is an event file in the song's folder. 31 of them, plus 2 shaders.

    Every big feature gets its own moment: texts and pictures, the callbacks, the HUD and the strum background, a whole modchart (lanes that jiggle, fly off the screen, scroll across it, turn upside down and ride a ring), the fight camera, the fighters (a dance, a death, a giant, swapping places), built-in effects and the song's own shaders. While it plays, a caption in the top left names each feature right as it starts.

    And it's meant to be taken apart: the event files are commented, so open them up, read them, and copy whatever you like into your own songs.

    Download the song (.zip)

    Unzip it into your songs folder (.minecraft/MineFunkin/client/songs/) and play Event Showcase at a Speaker - against the dummy or a friend. That's where it shines: the camera and the fighters only exist in a fight. In practice at the Retro TV everything else still runs.

    The song, part by part¶

    Part Bars What happens
    Intro 1-4 The screen switches on like an old TV - a dot, a line, the picture - with the title on it. The playfield starts to drift.
    Verse 1 5-12 Call and response. The camera follows whoever sings, your hits pop their lanes, your strumline leans toward the opponent's notes, the combo meter shouts at 25.
    Verse 2 13-20 A spotlight follows the melody, then the lanes get kicked around on the drum pattern.
    Build 21-24 Zoom, dark edges, shake and a 3-2-1. On the opponent's bar the lanes fly off the screen, then they spin.
    Drop 25-32 An impact: a shockwave knocks both fighters back. The playfield punches on the kicks, the strum background lights up, another shockwave, the lanes hop in turns.
    The dance 33-40 Both fighters stop their own animation and dance eight moves, mirrored. The camera swings round them; the words come in one by one.
    Fake death 41-44 The opponent drops dead, the colour drains, the lanes fall off the screen. A heartbeat - then it rises as a giant and the lanes shoot back up.
    Breakdown 45-48 The lanes spread across the whole screen and scroll sideways, wrapping round at the edges.
    Rebuild 49-52 The fighters jump over each other and swap places; two lanes come from the other side.
    Final drop 53-68 Every kick hits the picture, the logo bumps under the notes, the fighters swap back. The playfield turns upside down for four bars - the world stays upright - and back. Then a swap ping-pong.
    Outro 69-72 The lanes ride a ring, then drop out of it. The live score - and the TV switches off.

    Notice how the wildest moves (the lanes off the screen, the playfield turning over) only happen on bars where the opponent sings? That's on purpose - nobody has to play through them. And every effect keeps to its own property ("channel") or its own bars, so they stack without fighting each other - see strum[lane].

    The files¶

    All of them, in the order the song shows them (each file's first comment line has the same number).

    power_on.event 
    format 1.1
-- Event Showcase 1/31: the song switches on like an old TV - a dot, a line, then the picture - with the
-- title flickering in on the curved screen. After two bars the TV look fades away.
-- Shows: a song's own shader (shaders/crt.fsh) driven by its four numbers, after() for a sequence.

event {
    name = "Power On",
    color = #5CF2FF,
    category = "Screen",
    description = "The screen opens from a dot like an old TV, with the title on it.",
}

params {
    title    = text { from = "value1", default = "EVENT SHOWCASE", label = "Title" },
    subtitle = text { from = "value2", label = "Subtitle" },
}

local glowing = false

function onEvent(p)
    -- crt.fsh: a = curvature, b = open sideways, c = open up and down, d = scanlines.
    shader[0].file = "crt.fsh"
    shader[0].amount = 1
    shader[0].a = 1
    shader[0].b = 0
    shader[0].c = 0
    shader[0].d = 1

    -- A dot grows into a line, the line opens into the picture.
    tween(shader[0].b, 1, beats(1), "expoOut")
    after(beats(1), function() tween(shader[0].c, 1, beats(2), "expoOut") end)

    text[0].value = upper(p.title)
    text[0].x = 0.5
    text[0].y = 0.34
    text[0].size = 3.2
    text[0].color = #5CF2FF
    text[0].layer = "top"
    text[0].alpha = 0

    text[1].value = p.subtitle ?? ""
    text[1].x = 0.5
    text[1].y = 0.46
    text[1].size = 1
    text[1].color = #FF6EC7
    text[1].layer = "top"
    text[1].alpha = 0

    -- The title warms up with the tube: it flickers for a beat, then holds.
    after(beats(2.5), function() glowing = true end)
    after(beats(3.5), function()
        glowing = false
        text[0].alpha = 1
        tween(text[1].alpha, 1, beats(1))
    end)

    -- Two and a half bars later the TV look fades out and the title goes.
    after(beats(10), function()
        tween(shader[0].a, 0, beats(2), "sineInOut")
        tween(shader[0].d, 0, beats(2), "sineInOut")
        tween(shader[0].amount, 0, beats(2), "sineInOut")
        tween(text[0].alpha, 0, beats(1))
        tween(text[0].size, 4, beats(1), "expoIn")
        tween(text[1].alpha, 0, beats(1))
    end)

    after(beats(12), function()
        shader[0].file = ""
        text[0].value = ""
        text[1].value = ""
    end)
end

function onFrame(dt)
    if glowing then
        text[0].alpha = chance(0.6) ? random(0.5, 1) : 0.1
    end
end
    shaders/crt.fsh 
    // Overdrive's old TV: a curved screen with rounded corners and scanlines, which can open out of a
// line and close into a dot like a CRT switching on and off.
// params.x = curvature (0-1), .y = how far it's open sideways (0-1), .z = how far it's open up and
// down (0-1), .w = scanlines (0-1).
vec4 effect(vec2 uv) {
    vec2 c = uv * 2.0 - 1.0;
    c *= 1.0 + 0.1 * params.x * dot(c, c);

    // The picture squeezed into the open part: a thin line is the whole picture pressed flat.
    vec2 open = max(vec2(params.y, params.z), vec2(0.004));
    vec2 q = c / open;

    // A rounded rectangle: the corners round off with the curvature.
    float n = mix(40.0, 7.0, clamp(params.x, 0.0, 1.0));
    float e = pow(pow(abs(q.x), n) + pow(abs(q.y), n), 1.0 / n);

    if (e > 1.0) {
        return vec4(0.0, 0.0, 0.0, 1.0);
    }

    vec2 st = q * 0.5 + 0.5;
    vec3 col = pixel(st).rgb;

    // All the light pressed into the line: the tighter, the brighter.
    float squeeze = (1.0 - open.x) + (1.0 - open.y);
    col *= 1.0 + 3.0 * squeeze;

    col *= 1.0 - params.w * 0.2 * (0.5 + 0.5 * sin(st.y * resolution.y * 3.14159));
    // A brighter band rolling slowly down the tube.
    col *= 1.0 + 0.05 * params.w * sin((st.y + time * 0.3) * 6.2831);
    // Darker toward the curved edges.
    col *= mix(1.0, smoothstep(1.0, 0.8, e), params.x);

    return vec4(col, 1.0);
}
    caption.event 
    format 1.1
-- Event Showcase 2/31: names what's on screen. Each caption slides in from the left with its number and
-- slides out again; a newer one takes the place of an older one.
-- Shows: a counter kept for the whole song, a closure that checks whether it's still the newest.

event {
    name = "Caption",
    color = #B9A6FF,
    category = "Text",
    description = "A numbered caption top left: the event and what it uses.",
}

params {
    title = text { from = "value1", label = "Event" },
    line  = text { from = "value2", label = "What it uses" },
}

local count = 0

local function slideIn(slot, delay)
    text[slot].x = -0.5
    text[slot].alpha = 1
    after(delay, function() tween(text[slot].x, 0.03, beats(0.6), "backOut") end)
end

function onEvent(p)
    count += 1
    local mine = count

    text[5].value = (count < 10 ? "0" : "") .. count .. "  " .. upper(p.title ?? "?")
    text[5].align = "left"
    text[5].y = 0.11
    text[5].size = 1.1
    text[5].color = #5CF2FF
    text[5].layer = "top"
    slideIn(5, 0)

    text[6].value = p.line ?? ""
    text[6].align = "left"
    text[6].y = 0.11 + 0.065
    text[6].size = 0.7
    text[6].color = #F2ECFF
    text[6].layer = "top"
    slideIn(6, beats(0.15))

    after(beats(7), function()
        if count == mine then
            tween(text[5].x, -0.6, beats(0.6), "backIn")
            tween(text[6].x, -0.6, beats(0.6), "backIn")
        end
    end)
end
    cam_sway.event 
    format 1.1
-- Event Showcase 3/31: a handheld-camera drift.
-- Shows: onFrame(dt), noise() (smooth and repeatable), easing a script variable by hand, and reading
-- the shared "hype" value other events write - the louder the song gets, the more it sways.

event {
    name = "Cam Sway",
    color = #7CC8FF,
    category = "Screen",
    description = "The playfield drifts like a handheld camera. Off eases it back to rest.",
}

params {
    enabled = switch { from = "value1", label = "On" },
    amount  = number { from = "value2", default = 6, min = 0, max = 40, step = 1, label = "Drift (px)" },
}

shared hype = 0

local target = 0
local amp = 0
local moving = false

function onEvent(p)
    target = p.enabled ? p.amount : 0
end

function onFrame(dt)
    local goal = target * (0.6 + hype)

    -- Ease toward the goal at the same speed whatever the frame rate is.
    amp += (goal - amp) * min(1, dt / 500)

    if amp < 0.05 and goal == 0 then
        if moving then
            moving = false
            hud.x = 0
            hud.y = 0
        end
        return
    end

    moving = true
    hud.x = noise(time / 1100) * amp
    hud.y = noise(time / 1400 + 37) * amp * 0.6
end
    judge_glow.event 
    format 1.1
-- Event Showcase 4/31: every hit pops its lane, every miss shakes it.
-- Shows: onHit(note) and onMiss(note) with note.lane / note.judgment / note.offset, a function of your
-- own that returns a value, and the shared "hype" making the pops bigger in the drops.

event {
    name = "Judge Glow",
    color = #FFD166,
    category = "Lanes",
    description = "Hit notes pop their lane (bigger for better judgments), misses flash red and shake the lane.",
}

params {
    enabled = switch { from = "value1", label = "On" },
}

shared hype = 0

local active = false

-- How far a judgment pops its lane.
local function popFor(judgment)
    if judgment == "sick" then return 0.3 end
    if judgment == "good" then return 0.18 end
    return 0.08
end

function onEvent(p)
    active = p.enabled
end

function onHit(note)
    if not active then return end

    local lane = note.lane
    strum[lane].scale = 1 + popFor(note.judgment) * (0.7 + 0.5 * hype)
    tween(strum[lane].scale, 1, steps(3), "backOut")

    -- A dead-on hit (within 15 ms) also nudges the camera.
    if abs(note.offset) < 15 then
        camera.bump += 0.006
    end
end

function onMiss(note)
    if not active then return end

    flash.color = #FF2050
    flash.alpha = 0.22
    tween(flash.alpha, 0, beats(0.5), "quadOut")

    strum[note.lane].wobbleX = 12
    tween(strum[note.lane].wobbleX, 0, beats(0.6), "elasticOut")
end
    cam_follow.event 
    format 1.1
-- Event Showcase 5/31: the fight camera follows whoever sings. The opponent sings: it leans in toward
-- them. You sing: it pulls back and turns toward you. A bar without notes: back to the middle.
-- Shows: onHit and onOpponentHit as input, one value eased every frame that drives three properties.

event {
    name = "Cam Follow",
    color = #FFB35C,
    category = "Camera",
    description = "The fight camera leans toward whoever sings (0 = off).",
}

params {
    amount = number { from = "value1", default = 1, min = 0, max = 2, step = 0.1, label = "Strength" },
}

local amount = 0
-- -1 = you sing, 1 = the opponent, 0 = nobody.
local target = 0
local level = 0
local lastNote = -100000

function onEvent(p)
    amount = p.amount

    -- Off: let go at once and glide home, so another camera event can take over right away.
    if amount == 0 and level != 0 then
        level = 0
        tween(camera.x, 0, beats(1), "sineInOut")
        tween(camera.z, 0, beats(1), "sineInOut")
        tween(camera.yaw, 0, beats(1), "sineInOut")
    end
end

function onHit(note)
    target = -1
    lastNote = time
end

function onOpponentHit(note)
    target = 1
    lastNote = time
end

function onFrame(dt)
    if amount == 0 then return end

    if time - lastNote > beats(4) then target = 0 end

    level += (target * amount - level) * min(1, dt / 450)

    -- Toward the opponent: in and a little to the left. Toward you: back and to the right.
    camera.z = level * 0.6
    camera.x = level * -0.25
    camera.yaw = level * -1.5
end
    opponent_echo.event 
    format 1.1
-- Event Showcase 6/31: the strumline leans toward every note the opponent sings.
-- Shows: onOpponentHit(note), turning a lane into a direction with a function that returns early, and a
-- coloured vignette pulse.

event {
    name = "Opponent Echo",
    color = #A78BFA,
    category = "Lanes",
    description = "Each opponent note pushes your strumline a little in its arrow's direction.",
}

params {
    enabled = switch { from = "value1", label = "On" },
    push    = number { from = "value2", default = 8, min = 0, max = 40, step = 1, label = "Push (px)" },
}

local active = false
local push = 8

-- Left, down, up, right as x / y steps.
local function stepX(lane)
    if lane == 0 then return -1 end
    if lane == 3 then return 1 end
    return 0
end

local function stepY(lane)
    if lane == 1 then return 1 end
    if lane == 2 then return -1 end
    return 0
end

function onEvent(p)
    active = p.enabled
    push = p.push

    if not active then
        tween(strums.x, 0, beats(0.5))
        tween(strums.y, 0, beats(0.5))
    end
end

function onOpponentHit(note)
    if not active then return end

    strums.x = stepX(note.lane) * push
    strums.y = stepY(note.lane) * push
    tween(strums.x, 0, beats(0.75), "quadOut")
    tween(strums.y, 0, beats(0.75), "quadOut")

    vignette.color = #7C3AED
    vignette.alpha = note.hold ? 0.5 : 0.3
    tween(vignette.alpha, 0, beats(0.75))
end
    combo_meter.event 
    format 1.1
-- Event Showcase 7/31: a song script. The chart never calls this event - it runs from the first note to
-- the last just because the file is in the song folder, like a Psych song script.
-- Shows: onHit / onMiss without any chart event, player.combo, keeping state between callbacks, and a
-- colour that climbs the wheel with the combo.

event {
    name = "Combo Meter",
    color = #4ADE80,
    category = "Text",
    description = "No chart event needed: shouts every 25 combo, and tells you when a long combo breaks.",
}

local every = 25
local nextShout = 25
local lastCombo = 0

local function shout(message, tint)
    text[4].value = message
    text[4].x = 0.84
    text[4].y = 0.58
    text[4].color = tint
    text[4].alpha = 1
    text[4].angle = -8
    text[4].size = 1.8
    tween(text[4].size, 1.2, beats(0.5), "backOut")
    tween(text[4].angle, 0, beats(0.5), "backOut")
    tween(text[4].alpha, 0, beats(1.5), "quadIn")
end

function onHit(note)
    lastCombo = player.combo

    if player.combo >= nextShout then
        shout(nextShout .. " COMBO!", hsv(nextShout * 3 % 360, 0.7, 1))
        nextShout += every
    end
end

function onMiss(note)
    if lastCombo >= every then
        shout("COMBO BROKEN (" .. lastCombo .. ")", #FF4060)
    end

    lastCombo = 0
    nextShout = every
end
    spotlight.event 
    format 1.1
-- Event Showcase 8/31: a spotlight that follows the melody.
-- Shows: onHit and onOpponentHit sharing one function, per-lane tweens in a loop, a darker strum
-- background (underlay.alpha), and the shared "hype" turned down for the quiet part.

event {
    name = "Spotlight",
    color = #FFF27A,
    category = "Lanes",
    description = "Darkens the screen; only the lane of the note just sung (by you or the opponent) stays lit.",
}

params {
    enabled = switch { from = "value1", label = "On" },
    dim     = number { from = "value2", default = 0.25, min = 0, max = 1, step = 0.05, label = "Unlit lanes" },
}

shared hype = 0

local active = false
local dim = 0.25

local function light(lit)
    for lane = 0, 3 do
        tween(strum[lane].alpha, lane == lit ? 1 : dim, steps(2), "sineOut")
    end
end

function onEvent(p)
    active = p.enabled
    dim = p.dim

    if active then
        hype = 0.15
        vignette.color = #000000
        tween(vignette.alpha, 0.8, beats(1))
        tween(underlay.alpha, 0.9, beats(1))
        light(-1)
    else
        tween(vignette.alpha, 0, beats(1))
        tween(underlay.alpha, 0.65, beats(1))
        for lane = 0, 3 do
            tween(strum[lane].alpha, 1, beats(1))
        end
    end
end

function onHit(note)
    if active then light(note.lane) end
end

function onOpponentHit(note)
    if active then light(note.lane) end
end
    jiggle.event 
    format 1.1
-- Event Showcase 9/31: the receptors get kicked around on the rhythm and settle again - the modchart
-- "kick": a sideways jolt on 0, 0.75, 1.5 and 2.25 of every bar, an up-and-down jolt on 3 and 3.5, each
-- the other way round than the last.
-- Shows: onStep(n) as a rhythm grid, the wobble channels (they stack on .x / .y), local functions.

event {
    name = "Jiggle",
    color = #5CF2FF,
    category = "Lanes",
    description = "The receptors jolt on a rhythm and settle (pixels, 0 = off).",
}

params {
    amount = number { from = "value1", default = 24, min = 0, max = 60, step = 1, label = "Pixels" },
    rhythm = choice { from = "value2", options = { "kick", "beat", "eighths" }, label = "Rhythm" },
}

local amount = 0
local rhythm = "kick"
local flipX = 1
local flipY = 1

-- The whole row sideways.
local function side()
    flipX = -flipX
    for lane = 0, 3 do
        strum[lane].wobbleX = amount * flipX
        tween(strum[lane].wobbleX, 0, beats(0.75), "cubicOut")
    end
end

-- Up and down, every lane a bit differently (the cosine of the lane), so the row zigzags.
local function updown()
    flipY = -flipY
    for lane = 0, 3 do
        strum[lane].wobbleY = amount * 0.8 * flipY * cos(lane * 2)
        tween(strum[lane].wobbleY, 0, beats(0.75), "cubicOut")
    end
end

function onEvent(p)
    amount = p.amount
    rhythm = p.rhythm
end

function onStep(n)
    if amount == 0 then return end

    local s = n % 16

    if rhythm == "kick" then
        if s == 0 or s == 3 or s == 6 or s == 9 then side() end
        if s == 12 or s == 14 then updown() end
    elseif rhythm == "beat" then
        if s % 4 == 0 then side() end
    elseif s % 2 == 0 then
        if s % 4 == 0 then side() else updown() end
    end
end
    build_up.event 
    format 1.1
-- Event Showcase 10/31: the build-up before the drop.

    // A ring that runs out from the middle, bending the picture as it passes, with a cyan rim.
// params.x = strength, .y = speed (screen heights per second), .z = the moment it started (song
// seconds - a shader keeps no memory, so the script hands it the start).
vec4 effect(vec2 uv) {
    float age = time - params.z;

    if (age < 0.0 || age > 1.4) {
        return pixel(uv);
    }

    vec2 aspect = vec2(resolution.x / resolution.y, 1.0);
    vec2 d = (uv - 0.5) * aspect;
    float r = length(d);
    float ring = r - age * params.y;
    float fade = 1.0 - age / 1.4;
    float bend = exp(-(ring * ring) / 0.004) * params.x * fade;
    vec2 dir = d / max(r, 0.0001);

    // The three colours bent a little differently: a rainbow rim on the ring.
    vec2 off = dir / aspect * bend * 0.04;
    vec3 c = vec3(pixel(uv - off * 1.25).r, pixel(uv - off).g, pixel(uv - off * 0.75).b);
    c += bend * 0.22 * vec3(0.36, 0.95, 1.0);
    return vec4(c, 1.0);
}

    scroller.event 
    format 1.1
-- Event Showcase 23/31: the lanes spread out over the whole width of the screen and slide along it,
-- wrapping round at the edge - the modchart's scroller. Each one bobs toward the middle of the screen
-- while it travels. Switched off, they stop and glide home.
-- Shows: a lane's real spot on the screen (screen.width, strums.spacing), % to wrap round, an ease
-- written by hand (inOut) for values that aren't properties, the strum background faded meanwhile.

event {
    name = "Scroller",
    color = #5CFFB0,
    category = "Lanes",
    description = "The lanes spread across the screen and slide sideways, wrapping round at the edges.",
}

params {
    on    = bool   { from = "value1", default = true, label = "On" },
    speed = number { from = "value2", default = 1, min = -2, max = 2, step = 0.25, label = "Screens per 2 bars" },
}

-- 0 = idle, 1 = scrolling, 2 = gliding home.
local state = 0
local speed = 1
local onAt = 0
local offAt = 0
-- How far it has scrolled, in screen widths.
local pos = 0
-- The strum background's opacity before it faded.
local under = 0.65

local function inOut(t)
    t = clamp(t, 0, 1)
    return t < 0.5 ? 4 * t * t * t : 1 - pow(-2 * t + 2, 3) / 2
end

function onEvent(p)
    speed = p.speed

    if p.on and state != 1 then
        state = 1
        onAt = time
        pos = 0
        under = underlay.alpha
        tween(underlay.alpha, 0, beats(4))
    elseif not p.on and state == 1 then
        state = 2
        offAt = time
        tween(underlay.alpha, under, beats(2))
    end
end

function onFrame(dt)
    if state == 0 then return end

    local w = screen.width
    local s = strums.spacing

    -- A screen width every two bars, like the modchart (frozen while gliding home, so no lane wraps
    -- round on its way back).
    if state == 1 then pos += dt / beats(8) * speed end

    -- Spread from their own spacing to a quarter of the screen each, over a bar.
    local spread = inOut((time - onAt) / beats(4))
    local leave = state == 2 ? inOut((time - offAt) / beats(2)) : 0
    local gap = lerp(s, w / 4, spread)
    local left = lerp(w / 2 - 1.5 * s, w / 8, spread)
    local b = time / beats(1)

    for lane = 0, 3 do
        local home = w / 2 + (lane - 1.5) * s
        local x = (left + lane * gap + pos * w) % w
        local toMiddle = strum[lane].isDown ? -1 : 1
        local bob = toMiddle * screen.height * 0.05 * (1 + sin(b * pi + lane * pi / 2))

        strum[lane].x = (x - home) * (1 - leave)
        strum[lane].y = bob * spread * (1 - leave)
        -- A little see-through right at the edges, where a lane jumps round.
        strum[lane].alpha = lerp(1, clamp(0.35 + min(x, w - x) / 40, 0.35, 1), spread * (1 - leave))
    end

    if state == 2 and leave >= 1 then
        state = 0

        for lane = 0, 3 do
            strum[lane].x = 0
            strum[lane].y = 0
            strum[lane].alpha = 1
        end
    end
end
    switcheroo.event 
    format 1.1
-- Event Showcase 24/31: the fighters jump over each other and swap places - and back, as often as you
-- like.
-- Shows: player.x / .z and opponent.x / .z in the fight's frame, .turn by 180 so they still face each
-- other, a jump arc from two tweens, a variable that remembers which side they're on.

event {
    name = "Switcheroo",
    color = #5CFFB5,
    category = "Fighters",
    description = "The fighters jump and swap places. swap = to the other side, on / off = swapped / home.",
}

params {
    mode = choice { from = "value1", options = { "swap", "on", "off" }, label = "Mode" },
}

-- Where the opponent stands from you, in blocks: the default fight layout (7.4 ahead, 3 to the left).
local ahead = 7.4
local side = -3
local swapped = false

local function hop(who, x, z, turn)
    local dur = beats(1)
    tween(puppet[who].x, x, dur, "sineInOut")
    tween(puppet[who].z, z, dur, "sineInOut")
    tween(puppet[who].turn, turn, dur, "sineInOut")
    -- The arc: up for half the time, down for the other half; stretched in the air, squashed on landing.
    tween(puppet[who].y, 2.5, dur / 2, "quadOut")
    after(dur / 2, function() tween(puppet[who].y, 0, dur / 2, "quadIn") end)
    puppet[who].squash = -0.2
    after(dur, function()
        puppet[who].squash = 0.3
        tween(puppet[who].squash, 0, beats(1), "elasticOut")
    end)
end

function onEvent(p)
    local want = p.mode == "swap" ? not swapped : p.mode == "on"

    if want == swapped then return end

    swapped = want

    if swapped then
        hop(0, side, ahead, 180)
        hop(1, -side, -ahead, 180)
    else
        hop(0, 0, 0, 0)
        hop(1, 0, 0, 0)
    end
end

    halo.event 
    format 1.1
-- Event Showcase 29/31: the lanes ride round in a ring like a carousel - the modchart's halo. The ones
-- at the back are smaller and fainter, so it reads as a ring seen from the front. Fall: the ring keeps
-- turning and the lanes drop off the screen one by one.
-- Shows: x / y / scale / alpha from one angle per lane, a ring centred on the screen however the lanes
-- are spaced.

event {
    name = "Halo",
    color = #FFE35C,
    category = "Lanes",
    description = "The lanes ride round in a ring. Fall = they drop off the screen from it.",
}

params {
    mode = choice { from = "value1", options = { "on", "fall", "off" }, label = "Mode" },
}

local mode = "off"
local onAt = 0
local fallAt = 0
local level = 0

function onEvent(p)
    if p.mode == "on" and mode == "off" then onAt = time end
    if p.mode == "fall" then fallAt = time end
    mode = p.mode
end

function onFrame(dt)
    if mode == "off" and level < 0.001 then return end

    level += ((mode == "off" ? 0 : 1) - level) * min(1, dt / 350)

    local s = strums.spacing
    local rx = s * 2.4
    local ry = s * 0.55
    -- One turn a bar.
    local turn = (time - onAt) / beats(4) * 2 * pi

    for lane = 0, 3 do
        -- Starts with lanes 0 and 1 on the left, 2 and 3 on the right.
        local ang = 2 * pi * lane / 4 - 0.75 * pi + turn
        -- 1 = at the front, -1 = at the back.
        local depth = cos(ang)
        local toMiddle = strum[lane].isDown ? -1 : 1
        local fall = 0

        if mode == "fall" then
            fall = pow(clamp((time - fallAt - beats(lane * 0.25)) / beats(3), 0, 1), 3) * screen.height * 1.3
        end

        -- Around the middle of the screen: undo the lane's own place, then the ring.
        strum[lane].x = level * (rx * sin(ang) - (lane - 1.5) * s)
        strum[lane].y = level * (ry * depth + toMiddle * ry) + fall
        strum[lane].scale = 1 - level * 0.2 * (1 - depth)
        strum[lane].alpha = 1 - level * 0.25 * (1 - depth)
    end

    if mode == "off" and level < 0.001 then
        for lane = 0, 3 do
            strum[lane].x = 0
            strum[lane].y = 0
            strum[lane].scale = 1
            strum[lane].alpha = 1
        end
    end
end

    The music¶

    Two simple synth leads play the melodies: a hollow square wave for you, and a nasal pulse for the opponent. They're the song's two vocal tracks, so a miss mutes your lead.

    The music, both leads, the chart and the logo were made with a script; the event files and the shaders are written by hand.
