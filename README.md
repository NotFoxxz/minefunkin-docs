# MineFunkin Docs

The wiki for MineFunkin, a Friday Night Funkin' engine for Minecraft.

**Read it here: https://notfoxxz.github.io/minefunkin-docs/**

## What's inside

- **Event scripts** - guides for scripting your songs: flashes, zooms, modcharts, the fight camera, the fighters,
  stages, effects, shaders and the game window.
- **Event API** - every callback, action, shortcut, function and property, each with an example.
- **Songs** - what goes into a song folder, how to import a song, and the `.mfknsong` and `.mfkn` files.
- **Addon API** - for Java mods that want to use song results, fights and practice runs.
